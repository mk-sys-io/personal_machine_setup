# restic --exclude-file for Phase 40 backups (40-B).
#
# Format per upstream 040_backup (restic 0.18.0): one pattern per line,
# '#' comments + empty lines ignored. Patterns are matched against the
# full path on complete components; '**' only as a complete component;
# '!' re-include must follow the excluding line.
#
# Environment variables ARE expanded via os.ExpandEnv, so $HOME is the
# sanctioned home prefix (tilde '~' is NOT expanded — never use it).
# '**' is retained only for genuinely depth-agnostic names
# (node_modules, curated, models-store.json, .obsidian, searxng);
# home-rooted entries use $HOME (precise: matches only home's trees).
#
# Backup roots are chosen in 40-D (re-validate this file then). A missing
# file is fatal to restic itself (exit 1, no snapshot); 40-D's
# restic_common.py additionally stats it first and fails loud naming the
# exact path. Never confuse with etc/ark/domains/*/blocklist-exclude.txt
# (DNS tooling).
#
# §40.2 repo-mirror rule: if git clone + make all + ./install.py recreates
# it byte-identical, it is excluded here.

# Non-dot wholesale trees (dotfiles are denied by $HOME/.* below).
$HOME/Downloads
$HOME/go

# VMs / disk images / models (re-downloadables, non-dot).
*.iso
*.qcow2
$HOME/ISOs

# Repo mirrors + regenerables, nested (if a backup root ever contains them).
# $HOME/.* is top-level only, so these depth-agnostic patterns stay.
**/node_modules
**/node_modules/**
**/curated
**/models-store.json
**/.obsidian
# Upstream git clone backing lib/25-searxng.py (mirror rule: re-cloneable).
**/searxng
# This repo's own checkout (tools/bootstrap.sh clones it to ~/linux_setup).
$HOME/linux_setup

# System + secrets-never (D4 c1; WiFi is an owner ruling).
/opt/ark
/etc/NetworkManager/system-connections
/etc/network/interfaces

# Deny-by-default top-level dotfiles (pure mirror: config lives in git).
# $HOME/.* matches ~/.* nodes only, not nested dotfiles. Re-includes must
# follow the excluder; only true livedata is rescued.
$HOME/.*
!$HOME/.ssh

# keep/ re-include — keep these two lines LAST. Never a bare Videos line:
# once a directory itself is excluded, nothing inside can be re-entered,
# so the contents are excluded first and keep/ re-included.
$HOME/Videos/*
!$HOME/Videos/keep
